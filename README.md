# Матрица квартирографии

Агент заполняет лист «Квартирография (жилое)» по образцу ГП-10: штампы квартир с векторного PDF → строки Excel.

## Интерфейс агента

Публичная страница (GitHub Pages): загрузка PDF, ход прогона, метрики, выгрузка `.xlsx` или `.xlsm` в разметке шаблона ГП-10 (19 листов, 349 колонок, формулы). VBA макросов в браузерной выгрузке нет.

Обработка идёт в браузере. Файлы на сервер не отправляются.

`.rvt` в браузере не читается — нужен PDF планировок (экспорт из Revit/CAD).

## Локально

Откройте `docs/index.html` через любой статический сервер (модуль pdf.js с `file://` может не поднять worker).
